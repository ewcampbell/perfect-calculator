# perfect-calculator

the intention of this project is to build and ship a small, trivially simple project. i want to break the feeling of working on projects and not completing them. once one project is complete, the next project has something to emulate.

this project is a parody of a basic calculator app. it's a normal project for a programmer to make. the back-end is trivially simple because the UI directly translates to back-end function and programming language behaviors. so, my version is awkwardly functional because i think that's funny
